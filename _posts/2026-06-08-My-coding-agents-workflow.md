## Where do I spent most of my time as Software Engineer?

Huge advantage is in abstract thinking and designing of the solutions. This also gives chance to understand the problem space and solution space better and design better solutions. I have been using the coding agents to help me in this process of abstract thinking and designing solutions.
Brainstorming solutions and debating on pros and cons of different approaches with the agent, using the agent as a rubber duck to think through problems, etc.
Test driven development - writing tests first and then writing code to pass the tests. This helps in thinking through the problem and designing better solutions. I have been using the coding agents to help me in this process of test driven development, by writing tests first and then writing code to pass the tests.
