# What is inference optimization in LLMs?

What is the need for inference optimization in LLMs?
    - Latency reduction
    - Throughput improvement
    - Resource management

What is the playing field for the optimization paramters?
Minimize
- Latency - time taken to generate a response, TTFT, TPOT etc.
- Resource usage - how much compute and memory resources are used by the model during inference
Maximize
- Quality - how good is the response generated by the model
- Throughput - how many requests can be handled by the model in a given time

Techniques for optimizing inference in LLMs:
    Post training optimization techniques:
    - Pruning
    - Distillation

    While porting the model to production
    - Model compression and Quantization
    - Knowledge distillation

    While inferencing the model
    - Model parallelism
    - Pipeline parallelism
    - Disaggregated decoding - prefill and decode (TTFT reduction)
    - Continuous batching (TPOT decrease)
    - Speculative decoding (TTFT reduction)
    - KV cache optimization - (TPOT decrease)
    - Page attention - OS paging, memory management, etc. (TPOT decrease)
